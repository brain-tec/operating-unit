This module is a bridge between stock_operating_unit and product_operating_unit:

* Adds a rule for Lots so that users have only access to lots of products having no operating units or lots of products assigned to some of the operating units to which the user belongs.
* Modifies a rule for quants, so that it takes into account the information of the operating units in the products apart from the information about operating units in the location.

Configuration
=============

To configure this module, you need to:

* Assign Operating Unit to Products.
* Assign Operating Unit to Locations.
